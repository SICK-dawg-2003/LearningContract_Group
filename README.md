## App Features & Sections
The application presents 6 core sections styled inside clean Material CardView containers:

1. **Title Section**: Contract title, course information, and group header.
2. **Expectations**: Learning goals regarding Kotlin, Android UI, and Gradle project management.
3. **Contributions**: Individual and team contributions to development, standups, and debugging.
4. **Motivations**: Drivers for building software, career development, and portfolio creation.
5. **Hindrance & Mitigations**: Time management and technical learning challenges with concrete solutions.
6. **Signed By**: Formal signatures for all UniSync group members and course instructor.

---

## Tech Stack & Requirements
- **Language**: Kotlin 2.2.10
- **UI Framework**: Android XML Layouts (`ScrollView`, `LinearLayout`, `CardView`, `TextView`)
- **Gradle Version**: 8.7
- **Target JDK**: Java 11 / 21
- **Key Dependencies**: `androidx.cardview:cardview:1.0.0`

---

## How to Run the App
1. Open Android Studio.
2. Select **File ➔ Open** and select the project folder.
3. Allow Gradle to sync dependencies.
4. Select an Emulator or connected Android Device.
5. Click **Run ▶** (`Shift + F10`).
